## 语音（可选）
默认用 Edge 在线语音（晓晓，好听，需要网络）。想开：`powershell -ExecutionPolicy Bypass -File tools\install_edge_tts.ps1`。不装也没关系——**它就不出声**（不至于报错）；想要本机声音就把 `config\tts.json` 的 `引擎` 改成 `sapi`（机械）；不想让它说话就把 `config/tts.json` 的 `启用` 改成 `false`。

## 0. 30 秒了解

- **它是一个住在你桌面上的小角色**，会自己走动、发呆、打瞌睡；拖到屏幕边缘它会躲起来，鼠标靠近再探出头。
- **跟它说话**：右键 → `💬 对话`，在聊天窗里打字。回复由**你自己的 Agent**提供（默认支持 Hermes；也可以不接，那就是一只安静的桌宠）。
- **它会记住你**：人格、数值、记忆都是**明文文件**，放在你的用户目录里，你随时可以改、可以删。它**不上传任何东西**。
- **它不做主动注入**：不会往你和 Agent 的对话里偷偷加料。它只是把文件放在磁盘上，Agent 想了解它就自己去读。

## 1. 安装

现在还没有安装器，**解压即用**（以实际分发包为准）：

1. 把压缩包解压到一个**你有写入权限的目录**（例如 `D:\AIPet\`）。
   ⚠ **不要**放到 `C:\Program Files\`：这个程序要求它旁边的 `mods\` / `config\` 目录可读可改。
2. 确认目录里有这些（缺一不可）：
   ```
   MagicPet.exe          ← 主程序（名字以实际包为准）
   MagicPet.pck          ← 资源包
   data_.../             ← 运行时依赖目录
   mods\                 ← 动画与指令（**缺了它会变成不会动的空壳**）
   config\               ← **全部配置**：本地化 / 工具路径 / 行为 / 缩放 / 语音 / Agent —— **你主要改这里**
   licenses\             ← 许可文本
   ```
3. 双击 `MagicPet.exe`。首次启动 Windows 可能提示"未知发布者"（安装包没有代码签名）→ 选「更多信息 → 仍要运行」。

**系统要求**：Windows 10/11 64 位；一个可用的显卡驱动（程序用 GL Compatibility 渲染）。是否需要在系统里另装 .NET 运行时**以实际包说明为准（未验证）**。

## 2. 第一次运行会看到什么

- 桌面上出现一个**没有标题栏、透明背景**的小角色（窗口约 256×256，无最小化/最大化按钮）。
- **启动时会跟你打个招呼**（入场动画 + 招呼）。等 10–30 秒，它会自己走动一次；10 分钟不碰它，它会睡着。
- 第一次运行它会在用户目录里建好几个文件（见 §5），**不会**在程序目录里写东西。

**怎么退出**：没有标题栏 = 没有系统关闭按钮。**右键桌宠 → 面板底部的 `关闭`**。这是唯一的退出方式。

## 3. 怎么操作

| 想做什么 | 怎么做 |
|---|---|
| 移动它 | **左键按住拖**（把它**推过**屏幕边缘会贴边躲起来，鼠标靠近再探出） |
| 摸摸它 | **左键单击**（按下后别移动、直接松手）。它会有反应；如果它在睡觉，会先醒来打招呼 |
| 让它探出头 | 鼠标靠近它缩在的那条屏幕边缘 |
| 打开面板 | **右键**（聊天面板：上方聊天 + 底部命令栏 `工具栏 / 配置 / 状态 / 关闭`） |
| 跟它说话 | 右键 → `💬 对话` → 在聊天窗输入框打字回车 |
| 让它处理一段文字 | 复制到剪贴板 → **点一下它让窗口获得焦点** → `Ctrl + V` |
| 让它处理文件/文件夹 | 把文件**拖到它身上**（文件夹会递归枚举） |
| 让它干活 | 聊天面板命令栏 / 工具栏里的工具（如网速监控；具体以包里 `mods\` 为准） |
| 让它歇一会儿 | 面板 `关闭`；或改 `config\behavior.json` 关掉主动行为（§7） |

> ⚠ 旧 README 写的「**滚轮缩放**」**已经删除**（滚轮缩放会破坏动画对齐）。缩放请改 `config\pet.json` 的 `缩放` 后**重启**（只在启动时读一次）。

## 4. 接上你的 Agent（可选，但这是"会说话"的前提）

桌宠本身**不内置任何模型**。它通过 **ACP 协议**驱动一个外部 Agent CLI（默认支持 Hermes）：
桌宠拉起 `hermes acp` 子进程，把你的原话发过去，把回复显示回来。**没配 Agent 时它就是一个本地桌宠**（不发任何网络请求）。

### 4.1 配置

编辑 `config\agent.json`（或把一份改名放到数据目录，见 §5 的"覆盖规则"）：

```jsonc
{
  "backend": "hermes-acp",
  "executable": "C:/Users/<你的用户名>/AppData/Local/hermes/hermes-agent/venv/Scripts/hermes.exe",
  "arguments": "acp",
  "workingDirectory": "",          // 留空 = 用数据目录（**不要**指向含 AGENTS.md 的项目目录）
  "aggressiveMode": false          // true 会额外放开 open_url（打开网址）
}
```

- `executable` **留空** = 明确进入"无 Agent 本地模式"。
- `workingDirectory` **保持留空**：留空时用桌宠的数据目录，那里没有任何"项目契约文件"，Agent 的人格不会被别人写的 `AGENTS.md` 污染。
- 只有 Hermes 可执行文件路径不确定时：在命令行跑 `where hermes`（或 `hermes --version`）确认。

### 4.2 把 skill 交给你的 Agent（推荐）

桌宠**不会**把自己的状态硬塞给 Agent。要让它"知道"桌宠的存在、会读人格和记忆、会指挥桌宠做动作，需要把交付目录 `dist/skill/SKILL.md` **作为 skill 提交给你自己的 Agent**：

| 你的 Agent | 放哪 |
|---|---|
| Hermes | `%LOCALAPPDATA%\hermes\skills\aipet-desktop-pet\SKILL.md`（放好后用 `hermes skills list` 确认） |
| Claude Code | `~\.claude\skills\aipet-desktop-pet\SKILL.md` |
| 其他支持 skills 的工具 | 按其文档的 skills 目录（跨工具约定：`.agents\skills\`） |
| 没有 skill 机制的 Agent | 把 `SKILL.md` 正文并入它的规则文件，或直接作为第一轮对话的附件 |

### 4.3 连不上会怎样

- 没配 Agent：聊天窗状态行显示「未连接」，程序照常运行。
- 配了但连不上（路径写错、Hermes 没装好）：桌面会冒一个气泡「唔…我连不上「大脑」了，先自己待着」——**只提醒一次**，不会反复打扰。

## 5. 数据在哪（**这一节最重要**）

所有可变数据都在 Godot 的用户目录里，Windows 上是：

```
C:\Users\<你的用户名>\AppData\Roaming\Godot\app_userdata\AIPet\
```

> 程序名（项目名）是 `AIPet`，所以目录叫 `AIPet`；`AppData` 是隐藏目录，直接在资源管理器地址栏粘贴上面的路径最快。

| 文件 | 谁写 | 说明 | 能删吗 |
|---|---|---|---|
| `context.md` | **程序**（启动 + 事件池变动时） | **只读汇总**：数值摘要 + 画像 + 最近 12 条记忆 + 待处理事件 + 指令说明 + 所有动态文件路径（**不含人格/名字**——人格在 Agent 的内化里，名字是配置值）。Agent 读这一份就够 | 能（自动重建） |
| `soul\profile.md` | **Agent** | 用户画像（你是谁、在意什么、长期目标），≤ 5000 字 | 能 |
| `soul\memory.jsonl` | **Agent** | 记忆流水，一行一条 JSON | 能（=失忆） |
| `state/stats.json` | 程序（每 30 秒） | 主人情绪读数：`mood`（0–100，中性 50）+ 时间戳 | 能（回默认值：中性 50） |
| `events.jsonl` | 程序写；Agent 追加 ack | 行为事件流水（久坐提醒、你回来、任务完成…），上限 500 行 | 能 |
| `agent_session.json` | 程序 | 只存"上次会话 ID"，用于接着上次聊 | 能（=下次新会话） |
| `settings.cfg` | 程序 | 只存界面语言 | 能 |
| `<月-日>\`（如 `09-16\`） | 程序建、工具写 | 外部工具的产物目录 | 能 |
| `logs\godot.log` | 引擎 | **排查问题就看它**（⚠ 含你的对话内容，分享前先看一眼） | 能 |

**覆盖规则（改配置时的关键）**：`config\` 下的配置文件都有"数据目录优先"的读法 —— 想改某个配置，**把同名文件复制到上面那个目录**，改那份即可（例如数据目录里的 `behavior.json` 优先于程序目录的 `config\behavior.json`）。所有配置**改完重启生效**。

## 6. 改人格（和改名字）

**人格不在程序里** —— 程序侧不保存、不读取任何人格文件。人格住在**你的 Agent** 那里：

1. 让 Agent 读一遍随包交付的 `AIPet-SOUL.md`（内化材料：结构 + 示例），把桌宠的人格与职责写进它自己的人设。
2. 之后想调整：直接跟 Agent 说「把桌宠的性格改得……」；想重新内化一遍，就让它再读一次 `AIPet-SOUL.md`。

**改名字**（显示名，会出现在聊天窗标题上）：改 `config\config.json` 的「名字」（缺省「萝莉丝」）；改完重启桌宠生效。

**生日彩蛋**：同一文件的「生日」写 `MM-dd`（例 `"09-20"`）——当天启动会播一次生日动画 + 一句祝福；留空 = 不触发。

> 数据各归各位：数值归 `state\stats.json`、记忆归 `soul\memory.jsonl`、画像归 `soul\profile.md`；名字是配置，不是数据。

## 7. 想关掉某个功能

以下是全部"关法"。**改哪份**：把对应文件复制到数据目录（§5 覆盖规则）再改，改完**重启**。

| 想关什么 | 文件 | 键 | 值 |
|---|---|---|---|
| **所有主动行为**（它彻底安静下来，只被动反应） | `behavior.json` | `启用` | `false` |
| 环境感知（默认就是关的）：全屏时静默、你回来时打招呼 | `behavior.json` | `环境感知启用` | `false` |
| 贴边隐藏（拖到屏幕边缘会躲起来） | `behavior.json` | `贴边隐藏启用` | `false` |
| 爬边（它会走到屏幕边爬上墙、还会趴着爬、掉下来） | `behavior.json` | `爬边启用` | `false`（趴行仍会偶尔出现；想连趴行也关就设 `爬行概率` `0`） |
| 久坐提醒 | `behavior.json` | `久坐提醒分钟` | `0` |
| 自己走动 | `behavior.json` | `走动间隔最小秒` / `走动间隔最大秒` | 调大（如 `3600`） |
| 电脑全屏时是否完全静默 | `behavior.json` | `全屏静默` | `true`（默认） |
| **它出声说话（TTS）** | `tts.json` | `启用` | `false` |
| 面板底部某些指令 | `panel.json` | `隐藏指令` | 指令名数组（留空数组 = 全显示） |
| 缩放（角色大小） | `pet.json` | `缩放` | `0.5` 是默认（对齐原素材标准） |

> **语音输出**默认开：冒气泡时会念出来，默认用 **Edge 在线语音（晓晓）**（需要网络）。换声音/换引擎改 `config/tts.json`（不想联网就切 `sapi` = Windows 自带）。
> **语音输入**（喊关键词唤醒）默认**关**：需要自己准备 Sherpa-onnx 的模型文件并填 `config\tool.json`（进阶，见开发者文档）。

## 8. 卸载 / 重置

- **彻底删除**：删掉程序目录 + 删掉 `C:\Users\<你>\AppData\Roaming\Godot\app_userdata\AIPet\`（数据都在这里，程序目录没有你的数据）。
- **只重置数值**：删数据目录里的 `state\stats.json`，下次启动回默认（中性 50）。
- **只清空记忆**：删 `soul\memory.jsonl`（人格和数值不受影响）。

## 9. 隐私（一段话）

桌宠**不联网**（没有 HTTP/TCP 客户端、没有监听端口）；**不读**窗口标题、进程名、键鼠内容、屏幕内容；麦克风**默认不会打开**；环境感知默认关（开了也只读两个数：距上次输入的秒数、前台窗口是否全屏，**不落盘、不发给 Agent**）；事件池只记它自己的观察（时间、时长、状态机事件）。发给 Agent 的**只有你打的字**。所有数据是**明文文件**，就在 §5 那个目录里——你可以随时查看、修改、删除。
（依据：开发者文档 `document/隐私与权限模型.md`。）

## 10. 常见问题

| 现象 | 原因 / 怎么办 |
|---|---|
| 角色不动、右键菜单也没有指令 | `mods\` 目录没跟 exe 放在一起（或被杀软隔离）→ 补齐目录重启 |
| 聊天窗说话，状态行一直「未连接」 | 没配 Agent（`config\agent.json` 的 `executable` 为空）→ 见 §4 |
| 冒气泡说「连不上「大脑」」 | Agent 可执行文件路径不对 / Hermes 没装好 → 用 `where hermes` 确认真实路径；看 `logs\godot.log` 里 `[acp]` 开头的行 |
| 它突然出声说话，吓一跳 | TTS 默认开 → §7 关掉 |
| 改了 `config\` 里的配置没生效 | 配置要在**数据目录**里改（§5 覆盖规则），且**改完要重启** |
| 改完人格没变化 | 人格在**启动时**读一次 → 重启桌宠；Agent 那边要读 `context.md` 才会看到新内容 |
| 想让它别自己乱走 | §7：`behavior.json` 的 `走动间隔最小秒/最大间隔秒` 调大，或直接 `启用: false` |
| 拖到屏幕边缘躲起来后找不到了 | 鼠标贴到那条屏幕边缘就会探出头；或右键菜单/重启复位 |
| 找不到用户数据目录 | 资源管理器地址栏粘 `%APPDATA%\Godot\app_userdata\AIPet` |
| 想反馈问题 | 带上 `logs\godot.log`（**记得先检查里面有没有你不想公开的对话内容**） |
