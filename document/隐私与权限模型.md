### 2.3 边界说明（别误读）

- 「不外发」= **桌宠不主动推**。数据是**明文**躺在磁盘上的，本机任何进程（你装的 Agent、杀毒、别的软件）都可能读到 —— 这是**设计**（如果不想让 Agent 读到，就不该装这个 Agent）。
- 因此真正的隐私边界是 **本机文件权限**：想少留痕就少让它写（关环境感知、少聊天、定期清目录，见 §6）。**没有加密，也没有密码**（代码里无加密路径）。
- 日志会间接带上内容：`AgentBridge.cs:131` 把 **Agent 回复全文**打进日志，`AcpClient.cs:279` 把 **Agent 子进程 stderr** 打进日志。排查完可以删 `logs\`。
- 反面：Agent 出错时的**原始错误**（可能含路径/堆栈）现在只进日志，气泡只说固定文案（`ChatBox.cs:586-590`）——不会把内部细节显示在桌面上。

## 5. 本地安全（端口 / 执行外部命令的能力）

### 5.1 监听端口

- **没有监听任何端口。** 全仓库没有服务端实现（无 `TCPServer`/`HttpServer`/`WebSocket` 等）；与 Agent 的通道是**子进程 stdio 管道**（`RedirectStandardInput/Output/Error = true`，`AcpClient.cs:58-60`）。
- `config/agent.json:6` 里的 `"port": 8765` 只被读进配置结构（`AgentBridge.cs:92`），**没有任何后端使用它**（`AcpClient` 全文无 `Options.Port` 引用）。它是给「HTTP 兜底后端」预留的字段，而那个后端**还没实现**（`script/Agent/README.md:31`）。
- 绑定地址：**不适用**（没有 socket）。
- 本机实测（2026-09-16 14:44，编辑器里跑着桌宠实例）：该 Godot 进程在 `netstat -ano` 里**没有任何 LISTENING 或 ESTABLISHED 条目**（`netstat -ano | grep <PID>` 为空；核对时该进程 PID 28520，`tasklist` 里名叫 `Godot_v4.7.2-stable_mono_win64`）。自查方法见 §6 第 3 条。
- **注意**：Agent（Hermes）自己可能会开端口/连网络，那**不是桌宠**在做的事，需要单独问 Agent（不属本仓库 → 未验证）。

## 7. 未验证 / 已知缺口（诚实清单）

1. **Agent（Hermes）侧**：会话与记忆的落盘位置、它自己的网络行为与日志——不属本仓库，**未验证**。
2. **日志轮转**：`logs\` 的保留份数与体积上限是引擎行为，本仓库没配置，**未验证**。
3. **`user://` 目录里的非本项目文件**（如 `tts\vits.tar.bz2`，29 MB）：**当前代码不引用它**（全仓库 grep 无命中；现在的 TTS 决策是「不内置模型」（`Tts.cs:15-16`），没有任何模型下载路径），来源**未验证**（疑似早先 TTS 试验的残留）→ 可以连 `user://tts\` 目录一起删。注意该目录按项目名共享。
4. **KWS 全链路**（有模型时的真实开麦、采样率、CPU 占用）：本机没配模型，**未验证**。
5. **Steam 链路**：本机 Steam 未运行/AppId 未发布，只看到失败日志（`SteamNode.cs:27-31`）；正常连接后的行为**未验证**。
6. **mods 审计**：现有 mod 的 GDScript 有本机能力（§5.2 #5），**未逐个审计**；workshop 类 mod 未验证。
7. **与 `document/idea.md` 的差异（以实现为准）**：
   - `idea.md:179-188`（§5.1）列了 7 个感知项（天气 / CPU·GPU·内存 / 时间 / 系统通知 / 前台窗口 / 键鼠活跃度 / 电源）。**已实现的只有 2 项**：键鼠活跃度（空闲秒）与前台窗口**是否全屏**，且**默认关**；天气 / 宿主占用 / 系统通知 / 电源**一行代码都没有**（`grep` 无命中）。
   - `idea.md:270-271`（§8.3）写「单文件 10MB」，实现是**最多 500 行**（`EventPool.cs:31`）。
   - `idea.md:273-274`（§8.4）说「脱敏或删除」，实现方式是**写死的不记录边界**（不写窗口标题/进程名/键鼠内容），不是事后脱敏。
   - `idea.md:186` 的「前台窗口：主人正在用什么程序」**没有实现**（实现刻意不读窗口标题/进程名，`EnvironmentSense.cs:11-13`）。
8. **`port` 字段**：留着的死字段，未来若接 HTTP 后端就会真的开端口——接之前必须重新审这篇文档。
9. **分发包的配置面（新机制）**：配置查找多了「exe 同目录」一档（`script/Util/ConfigFile.cs:19-30`）——好处是导出后配置读得到，代价是**包里的配置会被信任执行**（`config/agent.json` 的 `executable` 会被 `Process.Start` 拉起，`AcpClient.cs:53-67`）。请只从信任的来源拿包。
10. 本文档**只覆盖本仓库代码**；用户自己装的 mod、Agent、第三方工具不在范围内。
