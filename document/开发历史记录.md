## 已拍板的关键决策（摘要）

- **定位**：Agent 驱动的桌宠前端（不是工具箱）——桌宠 = 脸和手，Agent = 脑；游戏 / 办公属性一体，不严格隔离。
- **人格与数据**：Agent **自主读取**（不注入、不推送、不碰 system prompt）；交付物 = 灵魂模板 + skill，由用户自己提交给自己的 Agent（**不注入本机**）。skill 与模板**在项目完工时才写**（P8）。
- **缩放**对齐官方内部 `ZoomRatio = 0.5`；动画一律以这个标准制作与验收。
- **数值**（`mood` = 主人情绪读数）：**只影响回复策略、不加入互动**（2026-09-20 主人定）；界面上只显示文字、不显示数字。
- **小组件自包含**：配置与数据放组件自己的目录（`mods/toolbar/<名>/`），删组件即一并删。
- **语音**：听 / 说**都保留**（不做删减）；不内置模型。**默认关**（`config/tts.json` 的 `启用=false`）—— edge（晓晓）能听但**偏机械，适合念文章、不适合桌宠**；后续方向＝**外接 API 或本地语音模型**（主人 2026-09-19）。`sapi` 仅作手动选项；合成失败**不出声**，不回退系统语音。KWS（听）接口在，但模型未随包、本机无麦克风。
