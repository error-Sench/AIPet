## 是什么

点击桌宠 → 无缝进入**横板动作游戏**（桌宠本体即游戏的一部分）；随时切回办公模式，进度保留。

- 交互设定（`document/idea.md` §6）：进入 = 右键双击（弹窗确认）或右键菜单「游戏模式」；操控 **WSAD + 空格跳跃**；默认**全屏无边框**，右上角「点击 X」或右键菜单退出。
- 决策不变式（主人已拍板）：（`GameSession` 独立容器，`user://game/save.json`）；办公模式表现不受游戏影响；**办公行为可作游戏内容**（如完成任务 → 游戏内奖励）。

## 边界（并行开发分工线）

| 归本目录 | 不归本目录 |
|---|---|
| 游戏场景 / 物理 / 关卡 / 玩法状态（`GameSession`） | 模式切换逻辑 → `script/Mode/`（接口已定：`SwitchMode` / `ModeChanged` 事件） |
| 游戏内 UI 与表现 | 办公模式表现 → `script/UX/`、`script/State/`（不动） |
| 游戏进度存取（save.json） | 灵魂层（记忆/数值/名字）、`mods/` 管线 |

> 并行开发（多 Agent / worktree）时，**本目录 = 游戏模式的所有权范围**；跨范围改动先在主线商量，别顺手改到别的层。
