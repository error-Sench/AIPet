# 手绘指南 —— 攻击（持械近战）& 起跳（主人亲绘版）

> 给主人：你画，我管导入 + 质检 + 接线。画完把帧丢进对应目录（见 §5）喊我一声就行。
> 开工包在本目录：底图 ×3 / 动作参考 ×2 / 官方色卡 ×1。

## 1. 画布与站位（硬规格，导入器就认这个）

| 项 | 值 | 说明 |
|---|---|---|
| 画布 | **512 × 512**，透明背景 | PNG，RGBA |
| 脚底线 | **y = 500**（底图红线） | 所有帧的脚都踩这条线（腾空帧除外：身体整体上移即可，落地帧必须回到线上） |
| 中心线 | **x = 270.5**（底图蓝线） | 角色身体跨这条线；最终居中由导入器微调，画的时候大致对上就行 |
| 角色高 | **≈489px**（底图绿线到红线） | ⚠️ 这是最容易翻车的一项：官方 fidget 小动作池（如 tennis）只有 63% 大，**别照它描比例**，照 idle/walk 底图描 |
| 朝向 | **默认画朝左** | 朝右版本 = 水平镜像，**我来生成**，你不用画两遍 |

## 2. 风格锚（照着官方帧来，色卡可吸色）

- **描边：纯黑 `#000000`，线宽 ≈3px**，封闭连续（官方帧纯黑占 7–10%，这是「看起来是同一个角色」的最大因素）
- **上色：平涂 + 同色系柔和渐变**（阴影 = 主色加深一档，不要换色相）
- **抗锯齿只在轮廓边缘**（官方半透像素 8–41% 全在边缘）；**内部不要噪点/喷枪/纹理**
- 颜色直接从 `风格-官方色卡.png` 吸（发银灰 / 肤白 / 裙红 / 袜白……）
- ❌ 避免：AI 生成感（颜色数爆炸、线稿发灰 `(16,16,16)`）、厚涂、发光特效大面积铺

## 3. 攻击（X 键）—— 持械近战，5 帧闭环

道具随你挑（小剑 / 法杖 / 逗猫棒 / 平底锅都行，Q 版比例），**道具和身体画在一起就行**（导入不分层）。

| 帧 | 姿势 | 参考 |
|---|---|---|
| `atk_000` | 起手：持械垂于身侧/扛肩，站姿 | 底图-站姿 |
| `atk_001` | 上举：器械举到头顶后侧，身体后仰蓄力 | tennis 帧 00–02 |
| `atk_002` | 蓄力顶点：后仰最大（可加 2–3 根短速度线） | tennis 帧 02 |
| `atk_003` | **挥出（发力帧）**：手臂完全伸展、器械挥到身前最远点 | tennis 帧 03/11/19 |
| `atk_004` | 收势 = **和 000 画一样的**（闭环回 idle 不跳变） | 复制 000 |

节奏：每帧 91ms（文件名后缀 `_91`），全程 ≈0.45s。挥出帧是灵魂——幅度最大、可以夸张。

## 5. 文件放哪 + 命名（命名决定帧率，别改格式）

```
tools/anim/new_assets/attack/left/   atk_000_91.png … atk_004_91.png
tools/anim/new_assets/jump/left/     jmp_000_125.png … jmp_002_125.png
```

`<前缀>_<三位序号>_<每帧毫秒>.png`——序号三位零填充（000/001/…），毫秒决定播放速率（91→11fps，125→8fps）。
**直接覆盖同名文件即可**（现在里面是 agent 的临时版，占位性质）。

## 6. 画法建议（Krita / CSP 都行）

1. 导入 `底图-站姿idle.png` 当**底层**（降低不透明度或开洋葱皮）
2. **Place and Trace**：在上面新建图层描身体轮廓——姿势变了的部分（手臂/腿）自己画，头/躯干/裙尽量描原帧
3. 多帧之间开**洋葱皮**（Krita：时间线面板洋葱皮开关）对着前一帧画，防漂移
4. 每帧画完隐藏底图层导出 PNG（512×512、透明背景）
5. 帧数不够/多了都行——改文件名序号就好，代码侧自适应
